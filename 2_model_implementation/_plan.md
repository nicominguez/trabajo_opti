# Outline de la Parte 2: implementacion


Convertir la formulacion de la Parte 1 en una herramienta reproducible que cargue datos CSV, resuelva el modelo y permita exportar los resultados.

## Tareas previstas

- Elegir las dependencias y la estructura tecnica del codigo.
- Implementar la carga de datos desde `data/`.
- Validar columnas, identificadores, valores y referencias.
- Construir y resolver el modelo.
- Distinguir datos invalidos de problemas inviables.
- Crear una interfaz Streamlit.
- Permitir modificar presupuesto y pesos.
- Mostrar seleccion, descartes, asignaciones y indicadores.
- Exportar los resultados principales a CSV.

## Entregables

- Codigo fuente.
- Dependencias necesarias.
- Instrucciones breves de ejecucion.
- Resultado reproducible para la instancia principal.
