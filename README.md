# Planificacion optima de un evento

Proyecto minimo de programacion lineal entera para seleccionar y programar actividades.

## Ejecucion

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

Los datos canonicos estan en `data/`. Las instrucciones originales estan en `instr/instr_trabajo.pdf`.
